# Trans association regions for Terra

Approved scope: define conservative candidate fine-mapping intervals from trans associations and study PLINK genotypes. Do not run fine-mapping or submit cloud jobs.

Use WDL 1.0. Input genotype shards contain one declared chromosome and three explicit File values (BED/BIM/FAM or PGEN/PVAR/PSAM). A chromosome-size File and genome-build label define coordinates. Association inputs are explicit Array[File], TSV/TSV.gz or Parquet, with configurable column names. Sample ancestry assignments contain IID and ancestry. Exact variant IDs must match genotypes; supplied positions must agree.

Prepare normalized significant associations and ancestry names once. Scatter over genotype shards and ancestry names. Each LD task selects group founders, records counts, calculates allele counts and retains biallelic variants with MAF strictly greater than 0.01. No MAC cutoff. Calculate PLINK 2 unphased r2 for every eligible associated variant against eligible variants in the search interval. Start at 1 Mb per side; double when a qualifying pair lies in the outer 100 kb, up to 10 Mb. Default r2 threshold 0.1. These are configurable heuristics, not inferred haplotype blocks. Missing, low-frequency or otherwise unassessable seeds remain explicit records. A seed with no qualifying reported LD pair has status no_reported_ld, which includes undefined or below-threshold correlations and does not establish independence.

Combine earliest and latest ancestry boundaries per seed. Add 100 kb padding. Retain a 1 Mb per-side fallback for a seed unassessable in every group. Search-limit hits retain the full searched span and are flagged unresolved. Expand every padded interval to at least 2,000,000 bp, symmetrically where possible; shift extension at chromosome ends. Then merge overlapping intervals; retain all associations and group evidence. No LD pruning or downstream variant inclusion list. Boundary expansion is to the original associated seed, not recursive single-linkage through every genotype variant. A distant disconnected LD segment beyond the searched span can be missed; report search radius and no independence guarantee.

Outputs: regions.tsv/BED (0-based half-open), region_associations.tsv.gz, compatible trans_window_associations.tsv.gz, ancestry_intervals.tsv.gz, seed_regions.tsv, QC summary, logs and parameter provenance. Keep all ancestry contributions including MID and ADMIX.

All opened inputs stay File-typed through WDL localization. Arrays become task-local newline lists at command rendering. Generated writer results stay File-typed through final placeholder localization; do not wrap them in sub or another String conversion. Python subprocess argument arrays avoid shell interpolation. No workflow-scope file writes. Required input readability is checked before computation. Build a micromamba image with pinned conda-forge/bioconda packages in GitHub Actions; image rebuilds on contained script changes only (plus explicit manual dispatch). Local tests do not build Docker. Synthetic real-PLINK smoke runs in GitHub Actions. Terra execution needs separate approval.
